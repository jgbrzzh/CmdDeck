# 1.2.0 使用与验收

本版实现所选 A、B、C、D、F、H、L、N、K。配置保存在 SQLite 的 `settings/productivity` 行，旧数据库不丢失已有预设。

| 功能 | 入口 | 行为 |
| --- | --- | --- |
| A 项目工作区 | 顶部下拉框、项目页 | 项目目录、Python / Node、环境变量、预设快捷入口、端口 |
| B 执行前检查 | 运行弹窗 | 检查目录、程序、绑定环境、参数、权限、安全与并发，提示端口占用 |
| C 任务状态 | 任务与端口 | Windows Job Object 进程树、CPU / 内存、停止与重跑 |
| D 日志 | 日志中心 | 按需查询当前 / 历史输出、逐行搜索、文本导出、容量控制 |
| F 通知 | 更新与通知 | 完成 / 失败、只通知失败、时长阈值、点击回到终端 |
| H 分屏恢复 | 终端布局工具栏 | 左右 / 上下，保存项目布局，恢复视图不执行命令 |
| L 备份 | 备份与分享 | 自动 / 手动快照，事务恢复，30 份上限，导出预览 |
| N 更新 | 更新与通知 | GitHub 正式版本、语义版本比较、更新说明、下载页面 |
| K 服务端口 | 任务与端口 | IPv4 / IPv6 TCP 监听、PID 归属、打开网页、停止自有任务 |

## 可复制验证命令

在项目根目录执行：

```powershell
npm ci
npm run build
cargo test --locked --manifest-path .\src-tauri\Cargo.toml
```

真实运行验收需独立数据目录，避免修改私人配置：

```powershell
$env:CMDDECK_DATA_DIR = Join-Path (Get-Location) 'test-results\v12-runtime'
$env:WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS = '--remote-debugging-port=9223'
npm run tauri:dev
```

另开 PowerShell 连接该窗口：

```powershell
npx --yes --package @playwright/cli playwright-cli -s=cmddeck-v12 attach --cdp http://127.0.0.1:9223
npx --yes --package @playwright/cli playwright-cli -s=cmddeck-v12 run-code --filename scripts/productivity-smoke.cjs
npx --yes --package @playwright/cli playwright-cli -s=cmddeck-v12 run-code --filename scripts/productivity-ui-smoke.cjs
```

后端验收检查本机已有 Python 与 Node，创建临时服务验证真实端口与进程，结束后停止服务。UI 验收需要位于预设 / 终端页面，截图保存在忽略的 `output/playwright` 中。

## 范围和限制

- 保存布局后重新启动，标签显示「命令尚未执行」。点击重新运行预设仍需填写参数并完成安全确认；空白 Shell 通过新建终端打开。
- 持续输出保留的是有上限的尾部，不是完整录像。历史日志删除后，SQLite 会复用空闲页，文件不会立即缩小。
- CPU 汇总当前任务进程树，单核为 100%，多核任务可能超过 100%。权限不足或任务退出时显示不可用。
- 端口面板目前只提供 TCP 监听端口，不扫描 UDP，不猜测服务协议；「打开网页」使用 `http://localhost:端口`。
- 配置快照只包含配置，不包含历史输出和审计；恢复保留现有运行记录。配置恢复时不会改变系统权限。
- 分享默认只排除结构化环境变量、工作目录与绑定字段；任意脚本里的路径、密码或令牌需要人工检查预览。
- 通知使用本应用 ID，并在当前用户的 `AppUserModelId` 下登记名称和图标。通知实际展示和点击行为仍需在正常桌面、通知开启的环境验收；注册失败会给出具体错误，不修改系统权限。
- 只在用户手动检查时访问 GitHub，不在后台轮询。更新检查受网络、代理、TLS 和 GitHub API 限流影响；失败时可打开下载页。
- 源码版本为 1.2.0，此次普通提交不会触发安装包构建或创建 Release。正式发布需明确版本标签或工作流输入。
